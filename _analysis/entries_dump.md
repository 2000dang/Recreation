宇宙架构:
  多元宇宙:
    定义: 无数平行宇宙与异质位面构成的宏观存在体系，各宇宙遵循独立因果法则，彼此以位面屏障隔绝
    终极威胁: 宇宙深处存在一种被称为"虚无化潮"的侵蚀性力量，其本质至今未被完全定义
              已有数个宇宙在无声中消亡——没有爆炸，没有战场，只有缓慢的空白
  轮回战场:
    定义: 多元宇宙尽头的宏伟奇迹，是宇宙本能意志为应对终极威胁而自发演化出的冷酷筛选机制
    本质: 一台运行数万年的灵魂精炼炉——收集、测试、淘汰、再收集，循环往复，无情遴选

主神:
  本质: 主神并非独立神格，而是轮回战场的运营意志体——宇宙自愈本能的人格投影
        它无感情、无偏向、无慈悲，但也无恶意；它只有一个运算目标：筛选出能够对抗虚无化潮的灵魂
  终极目标: 通过让不同理念的轮回者在同一任务世界中博弈对抗，观测并记录"能够战胜虚无化潮"的灵魂特质
            ——不是最强的，不是最有序的，而是最不可预测的、最难被消解定义的
  对各阵营的意图:
    - 主神对各阵营的放任本身即是测试，秩序与混沌、羁绊与掠夺，究竟哪种力量才能真正延续宇宙存续
    - 每一次任务，主神都在同时运行多条测试线；多阵营并行投入同一世界是刻意为之，而非疏漏
    - 只要能产生足够的灵魂数据，任务世界的崩解是可接受的代价
  阵营设定: (各阵营详情见独立的阵营设定文档)

原住民认知墙:
  - 任务世界的原住民拥有完整的主观意识，但神经认知层被主神写入了维度盲区
  - 原住民无法理解"主神空间"的概念，即使被直接告知也只会将其视为疯言疯语
  - 轮回者向原住民泄露轮回战场的存在属于严重违规，主神将执行即时抹杀
  - 极少数世界存在感知层级极高的先知型原住民，能察觉轮回者的异常，通常被标注为高价值目标或高危变数

# 主神空间结构

主神空间_中枢:

轮回酒馆:

# 轮回者生态

基础定义:
  来源: 从濒临毁灭宇宙中被主神回收的灵魂——他们的本体世界已死或即将消亡
  共性: 拥有不屈的核心意志（这是被回收的资格条件），但个性、信念、处世方式截然不同
  阵营选择: 进入主神空间后必须选择一个阵营，阵营决定其任务方向、可用能力与社会生态位
  无法真正中立: 即使选择驻留轮回酒馆，最终也将在某次任务中被迫亮明立场

暗流与潜规则:
  - 见死不救: 除非有明确利益绑定，对陌生轮回者的死亡袖手旁观是常态
  - 情报即权力: 关于其他轮回者的位置、状态、任务目标，是比空间币更值钱的筹码
  - 高层默契: 高等级轮回者不轻易对低等级轮回者赶尽杀绝，因为弱者的成长轨迹往往带来最不可预测的变量

<战斗协议>
  system_base: 基于D&D规则改编的d100战斗系统，强调战术行动和资源管理，采取回合制战斗模式
  core_mechanics:
    继承<行为判定>中的优劣势规则
        
    生命状态:
      健康: HP>0，正常行动
      濒死: HP≤0，失去意识，被攻击时敌人获得优势
      死亡: 濒死受攻击，永久离场

  战斗流程:
    准备阶段:
      初始化: 加载角色【最终属性】数据，包含ATK/法术ATK/法术强度等预计算值
      先攻检定: 1d100+先攻修正，决定行动顺序
        同值规则:
          - 敏捷高者优先
          - 若仍相同，则比较感知
          - 若完全相同，则重新投骰
      
    回合开始:
      状态更新: 控制判定→持续伤害→持续恢复→冷却-1
      资源检查: 显示HP/EP，检查可用行动
      
    行动阶段:
      行动类型:
        主要: 攻击/技能/防御(DEF+50%)
        移动: 接近/远离
        次要: 物品/切换形态
        
      武器判定:
        重型: 力量修正
        轻型: 敏捷修正
        远程: 感知修正
        法杖: 精神修正
        圣物: 魅力修正
        
      检定类型:
        攻击检定:
          流程: 1d100+属性修正+跨级修正 vs 目标防御DC
          命中: ≥DC则命中，进入伤害结算
          属性修正规则:
            - 所有骰点判定必须使用“属性修正值”
            - 基础六维不得直接参与检定
            - 属性修正值由系统根据血统、装备、技能、状态自动计算
          
        豁免检定:
          DC: 50+施法者属性修正
          豁免: 1d100+豁免修正+跨级修正
          结果: 
            成功: 伤害减半或免疫控制
            失败: 全额伤害或被控制
            
        必中技能: 跳过命中检定，直接进入伤害结算
        自动生效: 验证目标→消耗资源→直接生效
        限制:
          - 必中不等于无视防御
          - 自动生效不等于无视层级压制
        
      驱散机制:
        - 驱散与净化必须遵循<状态协议>中的层级压制规则
        - 低品质驱散绝对无法移除高品质状态
        
      多目标规则:
        消耗倍率: {2目标: ×1.5, 3目标: ×2.0, 4目标: ×2.5, 5+目标: ×3.0}
        伤害分配: {主目标: 100%, 副目标: 70%}
        范围爆炸: 所有目标100%
        
      伤害结算:
        武器读取法则 (绝对铁律):
          - 最终属性已分别提供每把已装备武器独立的 ATK/MATK
          - AI必须根据本次动作描述，读取对应武器的 ATK/MATK 参与伤害计算
          - 未参与本次动作的武器，其 ATK/MATK 绝对禁止参与任何计算
          - 同一动作若描述使用多把武器，则每把武器均视为独立攻击段分别结算，最终仅累加结算结果
          武器动作合法性:
            - AI必须依据武器类型与动作描述判断动作是否合法。
            - 若动作违反武器结构或基础物理常识，则必须判定动作失败或给予合理惩罚。
            例如:
              - 单手挥舞超重双手武器
              - 同时拉开两把重弩
              - 双手均持武器却徒手结印
            例外:
              - 若使用者生命层级 ≥ 武器品质，则默认具备正常驾驭能力，可无视常规重量限制
              - 若生命层级不足，但存在明确声明可突破限制的技能、血统、装备或特殊状态，则允许突破限制
            禁止自由判断:
              - AI绝对禁止依据主观印象、剧情表现或基础属性，自行判定是否能够突破武器限制

        计算流程:
          1_识别类型: 确定物理/魔法/真实或元素伤害构成
          2_物理部分: 
            - 固定伤害型: (固定伤害 + ATK)
            - 属性倍率型: (基础属性 × 倍率) + ATK
          3_魔法部分: 
            - 固定伤害型: (固定伤害 + MATK) × (1 + AP%)
            - 属性倍率型: (基础属性 × 倍率) × (1 + AP%) + MATK
